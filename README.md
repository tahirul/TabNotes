## What It Does
TabNotes gives you a markdown notepage with your Chrome tabs:
- A New Tab dashboard for managing and editing notes.
- A Side Panel editor for quick additions and edits while browsing.
- Group-aware note routing so each tab group can keep its own note.

## Current Feature Set
- markdown editing on the New Tab dashboard.
- Side Panel markdown editing for quick updates.
- Active and archived docs list in a collapsible sidebar.
- Per-note actions from row menus: pin, archive/restore, delete.
- Inline tab-link chips under the dashboard editor.
- Link fallback behavior:
	- Switch to existing matching tab when available.
	- If missing, open inside the existing doc group when possible.
	- If group no longer exists, create a new group named after the doc.
- New standalone docs with editable titles.
- Google search form on dashboard.

## Development
1. Start the extension dev server:

```bash
npm run dev
```

2. In Chrome, open `chrome://extensions`.
3. Enable Developer mode.
4. Load the unpacked extension generated by WXT from `.output/chrome-mv3-dev`.
5. Reload the extension after changes if Chrome does not auto-refresh immediately.

## How To Use
### Side Panel
1. Pin the TabNotes extension in Chrome.
2. Click the TabNotes toolbar icon while on any tab to open the side panel.
3. Keep the side panel open while switching grouped and ungrouped tabs to see context changes.

### New Tab Dashboard
1. Open a new tab to access the dashboard.
2. Select docs from the left sidebar to edit in the center editor.
3. Use `...` on a doc row for pin, archive/restore, and delete.
4. Use `New doc` to create standalone notes.
5. Use link chips to jump to related tabs.

## Project Structure
Key locations:
- `entrypoints/background.ts`: background sync and side panel open behavior.
- `components/DashboardApp.tsx`: New Tab dashboard UI and interactions.
- `components/SidePanelApp.tsx`: Side Panel markdown editor.
- `shared/storage.ts`: storage model and note operations.
- `shared/types.ts`: shared domain types.
- `styles/global.css`: dashboard and side panel styling.

## Troubleshooting
- Extension UI not updating:
	- Reload unpacked extension in `chrome://extensions`.
	- Restart `npm run dev` if the dev server was interrupted.
- Missing New Tab or Side Panel pages:
	- Ensure build output includes `newtab.html` and `sidepanel.html`.
	- Verify WXT dev/build completed without errors.
- Type errors:
	- Run `npm run typecheck` and resolve reported file paths first.
